# V7 Brand Usage Standards

Authority: exact masters under `approved/` and the preserved owner approval records. This document consolidates those rules; it does not redraw artwork. Original source instructions are retained under `legacy/source-documents`.

## Identity roles

| Family | Placement | Rule |
|---|---|---|
| Horizontal green / cream | Website header/footer, email and digital communications | Same approved lockup and subtitle at all breakpoints; uniformly scale |
| Stacked green / cream / black | Documents, print, correspondence | Retain the exact outlined lettering |
| Horse master | Favicon, small brand accent, premium small embroidery | Preserve geometry; no replacement animal or monogram |
| Two-color seal / ivory-field seal | Formal certificates and selected donor/print collateral | Existing seal ink colors are locked exceptions |
| Solid-green / solid-white seal | One-color applications | Keep the internal negative space transparent |

Website subtitle: **Pediatric & Equine Therapy**. Seal descriptor: **Equestrian Center / EST. 2025**. Do not interchange them. The lowercase `fr` experiment is excluded.

## Color and type

Use forest #173A2E, cream #F3EEE4, gold #B08D57, deep green #0E2019. Gold is a restrained website/print accent; no gold decoration on core merchandise. The approved rope seal uses #003321 and #C58C29; these remain master-specific inks and do not change the website palette.

Libre Caslon Display: hero and section headlines. Libre Caslon Text: supporting serif headings, leads and italic emphasis. Hanken Grotesk: body, controls and tracked labels. Logo lettering is already outlined; do not retype it or substitute a font.

## Spacing and proof targets

| Asset | Clear space around visible artwork | Digital test target | Print test target |
|---|---|---|---|
| Horizontal | 0.25 x artwork height | 200 CSS px width | 70 mm width |
| Stacked | 0.20 x artwork height | 160 CSS px width | 45 mm width |
| Seal | 0.08 x diameter | 160 CSS px diameter | 40 mm diameter |
| Horse | 0.15 x artwork height | 24 CSS px; separately test 16/32/48 icons | 10 mm width |

These are previously approved **starting proof targets**, not validated manufacturing limits. Clear space is measured from visible art, not SVG canvas whitespace. Use actual-size digital, office-print and vendor proofs before declaring minimums production-ready.

## Merchandise

Small horse-only left-chest embroidery is the premium polo/quarter-zip/vest direction. Polo emblem scale is the reduced women's reference: 50% of the prior pilot's width and height. Earlier photos remain unchanged historical visual references; production dimensions must come from a supplier proof. Tonal green variants are explicitly approved exceptions to normal contrast expectations; do not replace them automatically. Caps use centered horse embroidery; throws use corner embroidery. Journals use the approved forest-green matte printed format, not rejected linen or leather. Youth hoodies are drawcord-free.

## Never

Do not stretch, trace, regenerate, recolor by filter, remove the subtitle, substitute `fr`, introduce a standing horse, alter seal rings/rope/date, add visual effects or select candidates/legacy art as production masters. PNG exports are convenience derivatives; SVG masters are production source files. Mockup photography is not supplier-ready print artwork.
