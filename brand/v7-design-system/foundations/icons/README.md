# Icon inventory

Existing horse icon exports are in [exports/icons](../../exports/icons/). The favicon and touch-icon snapshot is in [website-snapshot](../../exports/icons/website-snapshot/). Avatar and sponsor SVGs are preserved in this directory's website-snapshot subfolder; they are historical website references, not new V7 approvals. [embedded-icons.json](embedded-icons.json) preserves the dropdown indicator encoded in the website stylesheet. Asset paths and exact hashes are recorded in the package consolidation ledger.

Use exact approved horse vectors for new brand artwork. Retain descriptive labels for meaningful icons and hide purely decorative icons from assistive technology. Do not substitute legacy website graphics for approved V7 identity assets.
