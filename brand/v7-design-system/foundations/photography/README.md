## Use and crop rules

- Keep one distinct hero per page. Reserve the home horse-and-girl imagery for home. Do not reuse it for another page.
- Preserve the provided masters and existing exports. Create any future crop as a separately reviewed derivative; retain the master and record its source hash.
- Use the provided mobile pair and page-specific focal point. Keep faces and horses visible at narrow widths; retain enough open space and scrim contrast for readable text.
- The current website treats hero images as decorative (`alt=""`) because the adjacent heading and copy provide the page context. Add meaningful alternative text when an image communicates information absent from that copy.
- Avoid heavy filters, rounded frames, repeated heroes and stock-like corporate replacements. Confirm image rights and clinical/content approval before new publication; carried-forward files do not grant a new approval.
- The shop snapshot is historical, not an approved V7 merchandise hero. A replacement must use current approved product artwork and receive review before adoption.

## Ownership and related guidance

Copy selected, approved derivatives into the destination website’s own asset paths during an explicit change. Never link to this package or read the register from a website build. Moving or replacing V7 must not affect the website.

For merchandise hero product-image selections, see [approved hero product images](../../merchandise/APPROVED-HERO-PRODUCT-IMAGES.md). See [foundations](../README.md) and [page patterns](../../patterns/README.md) for broader use guidance.
