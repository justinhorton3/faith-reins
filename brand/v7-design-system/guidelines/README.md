# V7 usage guidance

The original 18-page printable guide is included below in six ordered, lossless PDF volumes. All content stays inside this package. Each file is below 25 MB for browser upload; the complete single-file edition was reduced from 107,394,953 to 84,343,199 bytes through lossless stream repacking, without downsampling or JPEG conversion.

Read volumes in order. Original page dimensions and text are preserved. All 18 complete-guide pages matched the original pixel for pixel at 144 dpi, and all 43 embedded images retain their dimensions and decoded pixels. Every split page was also compared with the complete guide at 72 dpi. Sizes, hashes and verification results are recorded in [PDF-VALIDATION.json](PDF-VALIDATION.json); ongoing package checks verify the committed volumes against those hashes.

The original PDF includes historical handoff descriptions and export destinations. Those pages remain unchanged to preserve the source. Current repository ownership and handoff instructions are in [MIGRATION.md](../MIGRATION.md): the website owns separate copies and never reads this package at runtime or build time.
