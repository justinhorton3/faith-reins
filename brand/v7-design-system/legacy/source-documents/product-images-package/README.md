# Faith Reins V7 Product Catalog

42 product-design documents and 84 original product/styled PNGs, copied unchanged from the V7 design-system package.

Start with [catalog index](merchandise/product-catalog/README.md). Product descriptions, proposed sizes and image links are in the individual Markdown files. All sizes for a design roll up to its single detail file.

## Folder structure

- `approved/product-images/`: unchanged PNG originals.
- `approved/horse/` and `approved/document-logo/`: exact production-artwork references used by the product records.
- `merchandise/product-catalog/`: catalog index, 42 detail files and machine-readable image manifest/catalog.
- `merchandise/*.md`: preserved approval records and sourcing notes.

The existing `v7-design-system` relative paths are retained for copying into the repository. No images were edited, resized, cropped, retouched or recompressed. ZIP compression changes the archive representation only; extracted image bytes match their source hashes.

82 images are approved visual references; two existing styled companion views remain separately identified in the manifest. Sizes and supplier specifications are proposed until the exact Printful products are configured. No store publishing, ordering setup or GitHub commit is included.
