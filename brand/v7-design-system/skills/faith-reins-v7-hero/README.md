# Reusable Faith Reins V7 image skill

Follow [SKILL.md](SKILL.md) whenever creating or revising Faith Reins category, store or website hero imagery. The [recipe template](EXAMPLE.json) is intentionally unusable until an actual unbranded source photo has been visually checked and hash-pinned. The exact-vector compositing/verification executable lives at `../../scripts/compose-approved-brand.py` (relative to this skill directory).

This skill is deliberately standalone within `v7-design-system`; the website must not import it or read approved assets at build time. To deploy hero images, review and copy only approved derivative files into website-owned public asset paths, then validate the category page and route.
