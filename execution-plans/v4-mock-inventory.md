## Shared components required by the mock system

These are not additional missing screens; they are required global components and have dedicated plans:

- Global header and mobile drawer: `shared-header.md`
- Global footer and link groups: `shared-footer.md`
- Hero image/text/action pattern: `wix-implementation-spec.md`
- CTA buttons, typography, color, grid, responsive behavior: `wix-implementation-spec.md`
- Media organization and responsive QA: `shared-media-and-qa.md`

The Pasture Hero candidate is not represented as a v4 production screen and remains excluded.

The repository also contains `page-shop.md`. Shop is a supporting product page in the site plan, but it is not one of the 21 page screens shown in this v4 PDF. It must not be presented as a v4-matched screen unless a shop design reference is approved.

## V4 fidelity rule

The PDF screen headline, body, and primary action take precedence over older plan copy. Each page build must copy the corresponding row's action and reconcile the page plan before Wix editing begins.
