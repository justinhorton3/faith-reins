# Header Execution Plan

## Goal

Build one global header that matches the v4 mock visual system and works cleanly on desktop, tablet, and mobile.

## Assets

- Logo: `images/supporting/logo.webp`
- Optional white logo for dark/mobile drawer: `images/supporting/logo-white.webp`

## Copy And Links

| Label | Destination | Notes |
|---|---|---|
| Logo | Home | Logo links home |
| Home | Home | Can hide on tight tablet because logo already covers Home |
| About | Our Mission | Top-level link |
| Services & Programs | Services And Programs | Top-level link |
| For Families | For Families | Top-level link |
| Get Involved | Give | Can later become a dropdown |
| Shop | Shop | Text link only; no icon |
| Donate | Give | Primary CTA button |

## Layout Instructions

- Desktop: logo left, nav center/right, Donate button far right.
- Tablet: keep logo, About, Services, For Families, Donate visible if space allows; move lower-priority links into More/hamburger before wrapping.
- Mobile: logo left, hamburger right. Put Donate first inside the menu. Only keep a visible Donate pill if it fits without crowding.
- Do not allow nav wrapping or overlap.
- Use v4 brand button styling for Donate, not default Wix blue.

## Validation

- Desktop widths: 1440, 1280, 1024.
- Tablet widths: 900, 768.
- Mobile widths: 430, 390, 375, 320.
- Confirm menu opens/closes, all links route correctly, Shop has no icon, Donate is always accessible, logo is crisp and links home.
