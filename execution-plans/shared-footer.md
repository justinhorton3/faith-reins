# Footer Execution Plan

## Goal

Build one global footer that matches the v4 mock, uses approved brand colors/type, and gives visitors clear next steps without feeling generic.

## Required Context

- `brand/brand-tokens.md`
- `execution-plans/wix-build-rules.md`
- v4 mockup PDF root file: `Faith-Reins-Website-Design-Review-v4.pdf`

## Assets

| Asset | Repo path | Wix folder | Required |
|---|---|---|---|
| Reverse/footer logo | `images/supporting/logo-white.webp` | `Site Files / supporting` | Preferred |
| Primary logo fallback | `images/supporting/logo.webp` | `Site Files / supporting` | Optional |

## Brand Requirements

- Use Forest Green `#0B4F3A` as the main footer field unless v4 indicates a lighter footer.
- Use Cream `#F6F1E7` or White `#FFFFFF` for text depending on background.
- Use Warm Gold `#C9A96B` only as a restrained accent/rule.
- Use Noto Sans for footer links, utility text, and contact info.
- Do not use default Wix blue for links or buttons.

## Desktop Layout

- Footer is global across all pages.
- Use a full-width Forest Green footer band.
- Logo/contact block sits left.
- Link groups sit right in clean columns.
- Donate CTA should be visible and styled as a primary or reverse CTA.
- Keep spacing generous but not oversized.
- Include a small copyright/legal line at the bottom.

## Tablet Layout

- Footer stacks into two columns.
- Keep contact block first.
- Link columns can wrap into two rows.
- Donate CTA remains visible near top or after contact block.

## Mobile Layout

- Single-column layout.
- Order:
  1. Logo
  2. Donate CTA
  3. Contact details
  4. Link groups
  5. Copyright/legal
- Links must be at least 44 px tap targets or have enough spacing.
- No text clipping at 320 px.

## Validation

| Mode | Widths | Pass criteria |
|---|---|---|
| Desktop | 1440, 1280, 1024 | Footer matches v4, aligned columns, readable contact info |
| Tablet | 900, 768 | Columns wrap cleanly, no cramped link groups |
| Mobile | 430, 390, 375, 320 | Single column, readable contact info, tappable links |

## Done Means

- Footer appears globally.
- Footer uses approved colors/type.
- All footer links route correctly.
- Contact details match the approved placeholder details.
- Draft is saved.
