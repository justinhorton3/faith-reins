Square, uppercase-tracked CTA button — use for the primary page action (Contact us, Support Faith Reins).

```jsx
<Button>Support Faith Reins</Button>
<Button variant="accent" href="/contact">Contact us</Button>
<Button variant="outline" size="sm">Send a referral</Button>
```

- `variant`: primary (green) · accent (gold — on green/photo grounds) · outline · outline-inverse
- `size`: md (page) · sm (header/footer)
- Pair with a `TextLink` for the secondary action rather than a second filled button.
