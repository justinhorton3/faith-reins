# Page patterns

| Pattern | Composition | Content constraints |
|---|---|---|
| Home | Shared header; home hero; five-service index; audience paths; herd/team; giving band; shared footer | Keep the horse/girl hero unique; verified testimonials only |
| Therapy | Unique therapy hero; individualized support; service explanation; session steps; related services; request CTA | Clinical services and EAL remain distinct; facts approved by clinical lead |
| Family | Unique hero; next steps; practical information; FAQs; callback CTA | Request/callback first; no clinical narrative in public forms |
| Provider | Referral steps; requirements; contact options | Route clinical information through approved intake channels |
| Giving | Unique hero; giving module; sponsorships; stewardship | Donation remains an explicit path; merchandise purchase is not described as equivalent to a donation |
| Product | Product and styled views; design/color; options; supplier-specific size guide; purchase state | No inferred fabrics, care, measurements, prices or stock claims |
| Team / horse | Unique hero; profiles; short verified biography; related CTA | Portraits and credentials require approval; sponsorship attribution must be accurate |
| Policy | Shared header; quiet title band; readable prose; footer | Legal/clinical copy uses separate content review |

Reuse `components/components.css` and component contracts. Template copy is illustrative and must not invent outcomes, staff credentials or endorsements. Known live-site contact/postal fields and testimonial provenance require a separate content check; this package does not change the website.
