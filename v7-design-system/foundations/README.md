# V7 Foundations — Implementation Reference

This folder contains **implementation tokens and guidance**, not additional logo masters. The production identity artwork lives under `../approved/` and is governed by `../BRAND-USAGE-STANDARDS.md` and `../ASSET-REGISTER.md`.

## Token authority

- `tokens.json` is the current structured handoff for the V7 palette, typography, spacing, breakpoints and layout.
- Treat values as implementation inputs, not permission to recolor or modify approved SVGs.
- The seal has intentionally distinct master-specific ink colors; do not replace them with general website colors.
- Website logo subtitle must remain **Pediatric & Equine Therapy**.
- The design system is not a new merchandise approval. Product-specific decisions belong in the product catalog and merchandise manifest.

## Integration checklist

1. Reference approved SVG masters directly; avoid tracing, flattening or regenerating them.
2. Map the token palette to semantic website variables (background, text, borders, controls); preserve adequate contrast.
3. Use Libre Caslon Display for editorial display type, Libre Caslon Text for supporting serif type, and Hanken Grotesk for body and UI.
4. Confirm header logo readability at desktop, tablet and mobile sizes without cropping or hiding the subtitle.
5. Check seal artwork against the approved master before preparing print or donor collateral.
6. Record any deviations and their approval in the asset register before release.

## Scope of this batch

Documentation only. No approved art, product imagery, or existing asset-register entries are altered.
